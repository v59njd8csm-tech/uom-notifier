# UoM DAI Notifier 📢

Στέλνει μήνυμα στο Telegram κάθε φορά που βγαίνει νέα ανακοίνωση στα
[Νέα του Τμήματος Εφαρμοσμένης Πληροφορικής](https://www.uom.gr/dai/ta-nea-toy-tmhmatos) του Πανεπιστημίου Μακεδονίας.
Τρέχει δωρεάν με GitHub Actions κάθε 2 ώρες, χωρίς να χρειάζεται ανοιχτός υπολογιστής.

## Πώς δουλεύει

1. Κατεβάζει τη σελίδα των νέων (περνώντας το μικρό JS "firewall" του uom.gr).
2. Διαβάζει κάθε ανακοίνωση: id, τίτλο, ημερομηνία, link.
3. Τη συγκρίνει με το `seen.json` (όσες έχει ήδη δει).
4. Για κάθε καινούργια στέλνει μήνυμα στο Telegram.
5. Σώζει το `seen.json` πίσω στο repo.

## Στήσιμο (περίπου 15 λεπτά)

### 1. Φτιάξε Telegram bot
- Στο Telegram άνοιξε το **@BotFather** και γράψε `/newbot`.
- Δώσε όνομα και username. Θα σου δώσει ένα **token**, κράτα το.
- Στείλε ένα οποιοδήποτε μήνυμα στο νέο σου bot.
- Άνοιξε στον browser `https://api.telegram.org/bot<TOKEN>/getUpdates`
  και βρες το `"chat":{"id": ...}`. Αυτός ο αριθμός είναι το **chat id**.

### 2. Δοκίμασε τοπικά
```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
python notifier.py
```
Την πρώτη φορά απλώς σημειώνει τις τωρινές ανακοινώσεις και σου στέλνει "ξεκίνησε".
Για να δεις ότι στέλνει ανακοίνωση, σβήσε μια γραμμή από το `seen.json` και τρέξ' το ξανά.

### 3. Ανέβασέ το στο GitHub
- Φτιάξε νέο repo και ανέβασε όλα τα αρχεία (μαζί με τον φάκελο `.github`).
- **Settings → Secrets and variables → Actions → New repository secret**:
  - `TELEGRAM_TOKEN`
  - `TELEGRAM_CHAT_ID`
- **Actions → Check UoM news → Run workflow** για πρώτη δοκιμή.

Από εκεί και πέρα τρέχει μόνο του.

## Ιδέες για επέκταση
- Περισσότερες πηγές: ανακοινώσεις Γραμματείας, eclass μαθημάτων.
- Φίλτρα λέξεων (π.χ. μόνο "εξεταστική", "δηλώσεις", "πρακτική").
- AI περίληψη του κειμένου κάθε ανακοίνωσης.
- Κανάλι Telegram για όλο το τμήμα αντί για προσωπικό μήνυμα.
